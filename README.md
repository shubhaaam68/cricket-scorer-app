# 🏏 Cricket Scorer

A web-based cricket scoring application built using HTML, CSS, and JavaScript.

## Features

- Team and player name setup
- 1st and 2nd innings
- Live score and wickets
- Overs and ball tracking
- Individual batsman statistics
- Runs, 4s and 6s tracking
- Strike rotation
- Wicket recording
- Dismissal types
- New batsman entry
- Ball-by-ball history
- Current run rate
- Target calculation for the second innings
- Match result
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Enter the team and player details.
4. Click **Start Match**.
5. Use the scoring controls to record the match.
